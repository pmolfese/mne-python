Add :func:`mne.preprocessing.remove_fmri_gradient_artifact` and the :class:`mne.preprocessing.GradientRemover` class to remove the fMRI gradient (imaging) artifact from EEG recorded during functional MRI using robust, volume-locked average artifact subtraction (AAS, :footcite:`AllenEtAl2000`). Artifact templates can exclude volumes using AFNI, FSL, or SPM motion estimates and waveform correlation, and template construction diagnostics are exposed by :class:`~mne.preprocessing.GradientRemover`. A new tutorial (:ref:`tut-fmri-gradient`) demonstrates the full workflow, by `Peter Molfese`_ and `Joshua Teves`_.
